Cloud Provider Comparison

Infrastructure Component | AWS | Microsoft Azure | Google Cloud Platform

Compute | EC2 | Virtual Machines | Compute Engine
Storage | S3 | Blob Storage | Cloud Storage
Networking | VPC | Virtual Network (VNet) | Virtual Private Cloud (VPC)
Identity and Access Management (IAM) | AWS IAM | Microsoft Entra ID (formerly Azure AD) | Cloud IAM


Which cloud provider offers the broadest range of services? Explain your answer.
AWS, and it's not particularly close. It had a nine-year head start on the competition, and it shows, there's a service for almost anything you could think of, including several you'll never need, like satellite ground stations. Being first to market clearly has its perks.

Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?
Azure, obviously. If a company is already living inside Active Directory, Windows Server, and Microsoft 365, forcing them onto AWS or GCP would just be creating problems that don't need to exist. Azure is the path of least resistance here, and sometimes that's exactly what a business needs.

Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?
Google Cloud, and honestly it should be, considering they invented Kubernetes and then handed the industry standard to everyone else for free. GKE is the reference implementation for a reason. Their AI/ML stack, including custom TPU hardware, backs that reputation up rather than just riding on it.

What similarities did you observe among the three cloud providers?
Strip away the branding and they're offering the same four things, compute, storage, networking, and IAM, just wearing different name tags. All three use pay-as-you-go pricing, all three run global data centers, and all three shift security responsibility onto the customer once you go past the infrastructure layer. The marketing teams would like you to think these platforms are wildly different. They're not.
