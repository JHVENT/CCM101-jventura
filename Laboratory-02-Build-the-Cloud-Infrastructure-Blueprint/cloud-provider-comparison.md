|---|---|---|---|

| **Storage** | Amazon S3 | Azure Blob Storage | Cloud Storage |

## Questions and Answers

### 1. Which cloud provider offers the broadest range of services?

**AWS (Amazon Web Services)** offers the broadest range of cloud services. It has been in the market longer than Azure and Google Cloud, which has allowed it to develop a large and diverse service portfolio.

AWS provides services for computing, storage, databases, networking, security, analytics, artificial intelligence, and many other areas.

### 2. Which cloud platform would you recommend for an organization that primarily uses Microsoft products? Why?

**Microsoft Azure** would be the best choice for an organization that primarily uses Microsoft products because of its strong integration with Microsoft's existing services, such as:

- Active Directory
- Windows Server
- Microsoft 365
- Microsoft SQL Server
- Other Microsoft enterprise applications

This integration can make it easier for an organization to manage existing systems and move workloads to the cloud.

### 3. Which platform is widely recognized for Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes services?

**Google Cloud Platform (GCP)** is widely recognized for its strengths in **Artificial Intelligence (AI), Machine Learning (ML), and Kubernetes**.

Google developed Kubernetes, which is now widely used for managing containerized applications. Google Cloud also provides services such as **Google Kubernetes Engine (GKE)** and various AI and ML tools for developing and deploying applications.

### 4. What similarities did you observe among the three cloud providers?

AWS, Azure, and Google Cloud have many similarities. All three provide the basic services needed to build and operate applications in the cloud, including:

- **Compute** – Running applications and virtual machines
- **Storage** – Storing files, data, and backups
- **Networking** – Connecting cloud resources and applications
- **Identity and Access Management (IAM)** – Managing users and permissions
- **Pay-as-you-go pricing** – Paying based on resource usage
- **Global infrastructure** – Providing cloud services across multiple regions

Although AWS, Azure, and Google Cloud use different names and offer different features, their main purpose is similar: providing scalable and flexible cloud infrastructure and services.
