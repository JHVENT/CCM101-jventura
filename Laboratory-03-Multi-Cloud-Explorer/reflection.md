 Reflection

Honestly, out of the three platforms, Google Cloud Platform impressed me the most. I went in expecting AWS to win by default just because it's the biggest name, but digging into GCP's AI and Kubernetes tooling changed my mind a bit. The fact that Google basically invented Kubernetes and built TensorFlow in-house makes their cloud feel less like a "me too" product and more like the natural extension of tools I already associate with them. It's the platform I'd be most curious to actually build something on.

At the same time, doing this comparison made it obvious how much AWS, Azure, and GCP actually resemble each other under the hood. Strip away the branding and every provider has the same basic building blocks: a compute service for running servers, an object storage service, an identity/access system, a managed SQL database, and a Kubernetes offering. They're all chasing the same core use cases — scalability, pay-as-you-go pricing, global data centers, they've just packaged it differently.

That's really where business requirements come in. A university tied to Windows Server isn't going to pick GCP just because it's trendy for AI, and a startup on a tight budget isn't going to over-engineer with enterprise-grade tools it doesn't need yet. Working through the client scenarios drove home that "best" cloud platform is basically a meaningless question without context, it always depends on existing infrastructure, budget, technical goals, and where the company is headed.

Playing the role of a Cloud Solutions Consultant was probably the most useful part of this whole mission. It's one thing to memorize service names; it's another to actually justify a recommendation to a "client" and defend it with real reasoning. It forced me to think about trade-offs instead of just facts.

By the end, my GitHub portfolio went from having zero cloud-related content to a full set of research notes, comparison tables, and consulting-style writeups — something I can actually point to and say I understand this space, not just that I read about it once.
